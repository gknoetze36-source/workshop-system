{# =========================================================================== Shared UI styles for the Settings and integration-connect screens. WHY THIS FILE EXISTS -------------------- The settings templates were written against a class vocabulary that was never defined in base.html or in static/css/. Specifically: .v-card .v-card-header .v-card-title .v-card-subtitle .settings-grid .metric-card .field None of those had a single rule anywhere in the project, so every element using them rendered as bare text on the page background -- which is exactly why Settings looked unstyled. This partial defines them, in the same design tokens base.html already exposes, so the markup finally matches the CSS. It is additive only. It does not override anything base.html sets, so including it cannot change how any other screen renders. Include it once, immediately after {% block content %}, on any settings or connect page: {% include "_settings_ui.html" %} =========================================================================== #}
